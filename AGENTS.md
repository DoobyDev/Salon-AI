# Repository Instructions

## Documentation Update Rule

Whenever app capabilities are added, removed, renamed, re-scoped, or materially changed, update:

- `docs/APP_FEATURE_RECORD.md`

This is mandatory for changes affecting:

- landing page / public marketing features
- Ask Lexi capabilities
- customer dashboard features
- subscriber dashboard features
- admin dashboard features
- booking flows
- revenue / accounting features
- billing / subscription features
- business operations features

## Update Standard

For every qualifying change:

- update the relevant feature section
- update role-specific summaries if affected
- append a dated note in `Feature Update Log`
- keep wording useful for both internal tracking and promotion

Do not treat this as optional or wait for the user to ask.
